# Политика конфиденциальности — «Српски од нуле»

_Вступила в силу: 2 октября 2026 года. Версия приложения: 2.25.0._

Коротко: приложение работает без аккаунтов, без аналитики и без рекламы.
Весь ваш прогресс хранится только на вашем устройстве. Разработчик не имеет
доступа к вашим данным и не может их прочитать, потерять или передать.

## 1. Какие данные хранятся и где

**Прогресс обучения** (выученные слова, серия дней, XP, настройки, избранное,
копилка ошибок) хранится локально на устройстве: в localStorage приложения и
в его резервной автокопии (IndexedDB). На Android система дополнительно
резервирует эти данные в ваш личный Google Drive средствами самой платформы
(Android Auto Backup) — доступ к ним есть только у вас, через ваш аккаунт
Google. Приложение не имеет серверов и не отправляет прогресс по сети.

**Загруженные пакеты озвучки** хранятся локально (IndexedDB) и служат только
для воспроизведения звука без интернета.

## 2. Сетевая активность приложения

Приложение обращается в сеть в трёх случаях:

- **Обновления** — проверка версии и загрузка APK с GitHub
  (github.com/maxihac-ux/srpski-packs). При обращении GitHub видит ваш IP-
  адрес по своим правилам; приложение не передаёт GitHub ничего, кроме
  стандартного запроса файла.
- **Докачка пакетов озвучки** — загрузка ZIP-паков с того же публичного
  репозитория. Содержимое запросов не включает никаких ваших данных.
- **Дневник разработки** — открытие страницы дневника по вашей кнопке.

## 3. Микрофон

Разрешение на микрофон запрашивается только для упражнения «Говорение».
Аудио обрабатывается на устройстве: встроенная модель Whisper или системный
распознаватель речи вашего телефона/браузера. Записи не сохраняются и не
отправляются приложением никуда. Отозвать разрешение можно в настройках
системы в любой момент.

## 4. Журнал работы и сообщения о сбоях

По желанию можно включить журнал — записи о событиях и ошибках приложения
(какая функция, какой код ошибки). Журнал хранится локально. Он может
покинуть устройство только двумя путями, оба — по вашей инициативе или
с явным согласием:

- кнопка **«В Telegram» / «Экспорт в файл»** в настройках;
- **автоотчёт при сбое**: если приложение упало, хвост журнала (последние
  записи об ошибке) отправляется боту разработчика — не чаще одного раза
  в 2 минуты и только при включённом логировании.

В журнале нет вашего имени, контактов, содержимого словаря и прогресса —
только технические события.

## 5. Напоминания

Ежедневное напоминание — локальное уведомление самого устройства. Оно
планируется приложением без участия сети; включается только по вашему
нажатию (онбординг или настройки) и выключается там же.

## 6. Чего у приложения нет

- аккаунтов и регистрации;
- аналитики, рекламы и трекеров;
- доступа к вашим контактам, файлам (кроме файла, который вы сами выбираете
  для импорта прогресса) и к другим приложениям.

## 7. Как удалить все данные

- **Сбросить прогресс** — Настройки → «Сбросить весь прогресс»;
- **удалить приложение** — система удалит все локальные данные, включая
  резервные копии в устройстве;
- резервная копия в Google Drive управляется настройками Android
  (Настройки → Google → Резервное копирование).
