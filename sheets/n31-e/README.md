## Предварительный вывод по CSV (сужение причины «абракадабры»)

- Жалобные файлы **не отличаются** от здоровых референсов по измеримым метрикам:
  длительность 1.872 с (у всех слов — фиксированный бюджет кадра), RMS −24…−28 dBFS
  (у референсов −20…−29), F0 165–210 Гц (женский голос, у референсов 163–210).
- Значит, причина **не** в громкости, обрезке или высоте тона — а в содержимом
  (что именно произнесено) и/или в самом TTS-источнике этих карточек.
- Направление следующего шага: прослушать 7 файлов рядом с референсами
  (строки CSV идут парами «слово + пример»), при необходимости — перегенерация
  этих карточек с другим текстом/голосом в аудио-паке.
